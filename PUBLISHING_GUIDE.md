# FRESCO — Production Publishing & Store Deployment Guide
=============================================================
This guide details the step-by-step procedures to deploy the FRESCO backend infrastructure and publish the mobile application to the **Apple App Store** and **Google Play Store**.

---

## 1. Cloud Backend & Database Deployment

The FRESCO backend is containerized with Docker and requires:
1. A managed PostgreSQL 16 database (e.g. Supabase, Neon, AWS RDS, or Railway PostgreSQL)
2. S3-compatible object storage for fruit photos (AWS S3 or Cloudflare R2)
3. A production domain with SSL/TLS (e.g. `https://api.frescoapp.com`)

### Option A: Railway / Render Deployment
1. Connect your GitHub repository (`JeremiahShadams/Shelf-Life`).
2. Add a **PostgreSQL** service on Railway/Render.
3. Add a **Web Service** using Dockerfile path `backend/Dockerfile`.
4. Configure the environment variables (see `backend/.env.production.example`):
   - `DATABASE_URL`: Your managed PostgreSQL connection URL (`postgresql+asyncpg://...`)
   - `SECRET_KEY`: Random 64-character secret key (`openssl rand -hex 32`)
   - `DEBUG`: `False`
   - `ALLOWED_ORIGINS`: `*`
   - `STORAGE_BACKEND`: `s3`
   - `S3_BUCKET`, `S3_REGION`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_PUBLIC_URL`
5. Railway/Render will automatically build the image, run database migrations, and expose an HTTPS endpoint (e.g. `https://api.frescoapp.com`).

### Option B: Docker Compose (VPS / AWS EC2)
```bash
git clone https://github.com/JeremiahShadams/Shelf-Life.git
cd Shelf-Life
cp backend/.env.production.example .env
# Edit .env with your domain and database credentials
docker compose up -d --build
```
Health check validation:
```bash
curl -f https://api.frescoapp.com/api/health
```

## 2. Mobile App Production Configuration

In `fresco-app/.env`:
```env
EXPO_PUBLIC_API_URL=https://api.frescoapp.com
```

### Install EAS CLI & Authenticate
```bash
npm install -g eas-cli
eas login
```

### Configure EAS Project
Inside `fresco-app/`:
```bash
eas project:init
```

## 3. Google Play Store Submission (Android)

### Step 3.1: Build Production Android App Bundle (`.aab`)
```bash
cd fresco-app
eas build --platform android --profile production
```
EAS Build creates an optimized, signed Google Play App Bundle (`.aab`).

### Step 3.2: Google Play Console Setup
1. Log into [Google Play Console](https://play.google.com/console).
2. Click **Create app**:
   - **App name**: FRESCO - Fruit Freshness & Shelf Life
   - **Default language**: English (US)
   - **App or game**: App
   - **Free or paid**: Free
3. Complete **App Content** setup:
   - **Privacy Policy**: Enter your hosted URL (or point to `https://github.com/JeremiahShadams/Shelf-Life/blob/main/PRIVACY_POLICY.md`).
   - **App access**: All functionality available without restrictions (or provide test credentials `demo@frescoapp.com` / `Password123!`).
   - **Target audience**: 13 and older.
   - **Data safety**:
     - Photos/Videos: Collected for app functionality (fruit freshness assessment).
     - User account info (email, username).
4. Store Listing details:
   - **Short description**: AI-powered fruit freshness analyzer, expiry tracker, and storage guide.
   - **Full description**: FRESCO uses computer vision and post-harvest agricultural data to determine produce freshness and calculate optimal storage recommendations across counter, fridge, and freezer.
   - **App Icon**: 512x512 PNG.
   - **Feature Graphic**: 1024x500 PNG.
   - **Screenshots**: Upload phone screenshots (at least 4 showcasing Scan, Results, Inventory, and Storage Checker).
5. **Release Track**:
   - Go to **Production** > **Create new release**.
   - Upload the `.aab` generated by EAS Build.
   - Review and roll out to production!

## 4. Apple App Store Submission (iOS)

### Step 4.1: Build Production iOS Archive (`.ipa`)
```bash
cd fresco-app
eas build --platform ios --profile production
```
EAS handles code signing, distribution certificates, and provisioning profiles automatically via your Apple Developer account.

### Step 4.2: App Store Connect Setup
1. Log into [App Store Connect](https://appstoreconnect.apple.com).
2. Click **My Apps** > **+** > **New App**:
   - **Platform**: iOS
   - **Name**: FRESCO Produce Tracker
   - **Primary Language**: English (US)
   - **Bundle ID**: `com.fresco.app`
   - **SKU**: `fresco-ios-app`
3. Prepare Version Information:
   - **Screenshots**: Upload 6.7" iPhone (iPhone 16 Pro Max / 15 Pro Max) and 5.5" iPhone screenshots.
   - **Promotional Text**: Know your fruit and keep produce fresh longer.
   - **Description**: FRESCO helps you scan fruits, predict truthful shelf life, prevent spoilage, and check ethylene compatibility.
   - **Keywords**: fruit, freshness, grocery, shelf life, food waste, expiration, fridge inventory
   - **Support URL**: `https://frescoapp.com/support`
   - **Marketing URL**: `https://frescoapp.com`
4. App Review Information:
   - **Sign-in required**: Yes (provide demo account email + password).
   - **Notes**: "Camera permission is used to capture fruits for computer vision classification. App Store Guideline 5.1.1 compliant account deletion is located under Account > Delete Account."
5. **Submit for Review**:
   - Use EAS Submit:
     ```bash
     eas submit --platform ios
     ```
   - Select the build in App Store Connect and click **Submit for App Review**.
